# Google Apps Script（GAS）で使う

FIVE READERS を GAS の「ウェブアプリ」として公開し、URL を開くだけで遊べるようにする手順です。
ゲームはブラウザの中だけで動くので、Google ドライブやスプレッドシートの権限は使いません。

用意するのはこのフォルダの `Code.gs` と、リポジトリ直下の `Index.html` の2つです。

## 1. プロジェクトを作る

1. <https://script.google.com> を開き、「新しいプロジェクト」を押す。
2. 左上の「無題のプロジェクト」を押して、名前を付ける（例：FIVE READERS）。

## 2. 2つのファイルを貼り付ける

1. 最初からある「コード.gs」の中身をすべて消し、`gas/Code.gs` の中身を貼り付ける。
2. 左の「ファイル」の横にある「＋」→「HTML」を押し、名前を **`Index`** にする（`.html` は自動で付く）。
3. できた `Index.html` の中身をすべて消し、リポジトリの `Index.html` の中身を**丸ごと**貼り付ける。
   - GitHub で `Index.html` を開き、右上の「Copy raw file」（コピーのアイコン）を押すと全文をコピーできます。
   - 6,000行以上（約730KB）ありますが、そのまま貼り付けて問題ありません。
4. 保存する（Ctrl＋S／⌘＋S）。

ファイル名は `Index` と完全に同じにしてください（`Code.gs` の `createHtmlOutputFromFile('Index')` がこの名前を探します）。

## 3. 公開する（デプロイ）

1. 右上の「デプロイ」→「新しいデプロイ」を押す。
2. 「種類の選択」の歯車 →「ウェブアプリ」を選ぶ。
3. 次のように設定して「デプロイ」を押す。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：使う人に合わせて選ぶ
     - 学校の Google Workspace の生徒だけ → 「（学校名）内の全員」
     - Google アカウントを持つ人なら誰でも → 「Google アカウントを持つ全員」
     - ログインなしで誰でも → 「全員」
4. アクセスの承認を求められたら、自分のアカウントで許可する。
5. 表示された「ウェブアプリ」の URL を配布する（Classroom に貼る、QR コードにする など）。

公開前に自分だけで確かめたいときは、「デプロイ」→「デプロイをテスト」の URL を使えます。

## 4. ゲームを更新したとき

URL を変えずに中身だけ差し替えられます。

1. `Index`（必要なら `コード.gs` も）を新しい内容に貼り替えて保存する。
2. 「デプロイ」→「デプロイを管理」→ 使っているデプロイの鉛筆（編集）を押す。
3. 「バージョン」を「新バージョン」にして「デプロイ」を押す。

貼り替えて保存しただけでは、配布した URL の中身は変わりません（3. まで必要です）。

## GAS で使うときの注意

- **設定の保存**：出題範囲や難易度などは、各自のブラウザに保存されます。別の端末・別のブラウザには引き継がれません。
  保存できないブラウザ（プライベートモードなど）では、設定画面に「この表示環境では設定を保存できません」と出ますが、ゲームは遊べます。
- **全画面ボタン**：GAS のウェブアプリの中では全画面にできないため、押すと案内が出ます。
  Windows は F11、Mac は Control＋Command＋F でブラウザごと全画面にしてください。
- **スマホ**：`Code.gs` で画面幅の設定を付けているので、スマホでも縮小されずに表示されます。
- **「問題を編集」**（漢字モード）で差し替えた問題は、ページを開き直すと元に戻ります。
- 自分以外が開くと、ページの上に Google の注意書き（別のユーザーが作成したアプリである旨）が出ることがあります。
- **Google サイトなどに埋め込む**場合は、`Code.gs` の `setXFrameOptionsMode` の行のコメント（先頭の `//`）を外してから、もう一度デプロイしてください。
